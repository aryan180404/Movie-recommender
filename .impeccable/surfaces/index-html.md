# Surface: index.html (recommender page)

Mode: operate. Audience: someone choosing what to watch. Task: one film in, five films out, then follow a result into the next search.

## Direction contract

THESIS: The match is a physical join. The visitor's film is the source, and each recommendation is spliced to it by a line that carries what the two films share.

FORM: Projection booth labels. seed:5fad701ae57a79f5 (degraded roll, no challengers). The world lends type (sturdy label grotesque, condensed caps for labels), palette (pale grey-green stock, deep booth teal shell, orange for the visitor's pick and primary action, teal for matches), density, and one signature move.

FIRST VIEWPORT: A deep teal header band holding the title, one line of explanation, the search field and Recommend button, and starter films. Below it, on pale stock, the results area and then the catalogue with its filter.

SIGNATURE: The splice. An orange node beside the chosen film, a line running down from it, numbered nodes branching to each result, the shared traits written at the branch. The line draws in when results arrive.

CONTROLS: Standard web input, button, listbox, links. No label costume on controls.

RISK: Without posters the page is all text; the splice has to carry the character.
